# Android: список пользователей

Учебное приложение на Kotlin: список пользователей, слои data и domain, ViewModel и сервисы.

**Стек:** Kotlin · Android Studio · Gradle

## Что внутри

- `app/` — приложение
  - `data/` — DTO, репозитории, сервис и широковещательный приёмник
  - `domain/` — модели и use case
  - `presentation/` — Activity, ViewModel и фабрики

## Запуск

Открыть проект в Android Studio и запустить на эмуляторе или устройстве.
